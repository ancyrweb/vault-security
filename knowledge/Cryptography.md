**Cryptography** provides the building blocks for protecting data: one-way hashing, two-way encryption, and signatures that prove data hasn't been altered.

## One-way
- [[Hashing]]: a digest that can't be reversed, for data you never need to see again such as passwords

## Two-way
- [[Symmetric Encryption]]: the same key encrypts and decrypts
- [[Asymmetric Encryption]]: the public key encrypts, the private key decrypts

## Applied
- [[Digital Signature]]: proves a file hasn't been altered
- [[Transport Layer Security|TLS]]: every API call should use it
- [[Database Encryption]]: manual encryption of sensitive fields, or transparent encryption at rest
