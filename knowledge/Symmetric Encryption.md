**Symmetric encryption** is two-way encryption where the same key both encrypts and decrypts.

- Encrypt the data with the key to get ciphertext.
- Decrypt the ciphertext with the same key to get the data back.
- Can be applied manually to sensitive database fields; see [[Database Encryption]].
