**Database encryption** protects sensitive information stored in a database.

## Approaches
- **Manual**: encrypt sensitive data with [[Symmetric Encryption]]. Downside: encrypted data can't be searched.
- **Encryption at rest**: databases are stored as files, and those files can be encrypted. This happens transparently.
