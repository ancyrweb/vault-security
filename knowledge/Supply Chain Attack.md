A **supply chain attack** compromises a system through the digital components used to build and run it: the IDE and its extensions, libraries, cloud environments. Rule: **never trust the supply chain**.

## Mitigation
- Remove unneeded dependencies.
- Remove unneeded IDE extensions.
- Run dependency checks.
- Harden environments: users and developers get only the tools they need.
- Set user permissions carefully.
